# CodeAlpha Data Analytics - Task 2: Exploratory Data Analysis (EDA)

## 📖 Overview
Performs comprehensive Exploratory Data Analysis on the scraped book dataset (`books_scraped.csv`).

## 📁 Files
- `eda_analysis.py`: Python script performing statistical summary, distribution checks, outlier detection, and correlation analysis.
- `books_scraped.csv`: Scraped input data (1,000 records).
- `eda_summary_report.txt`: Generated statistical summary report.
- `requirements.txt`: Dependencies for EDA.

## 🛠️ Installation
```bash
pip install -r requirements.txt
```

## ▶️ How to Run
```bash
python eda_analysis.py
```
This prints the full analytical findings to the terminal and saves `eda_summary_report.txt`.
